# Agent session bootstrap (tool-agnostic)

Before editing this repository:

1. Read **`AGENTS.md`**
2. Read **`CONSTITUTION.md`**
3. Read **`DOMAIN_MODEL.md`**
4. Read **`knowledge/INDEX.md`**
5. Read **`knowledge/context-packs/repo-context.md`**
6. Read relevant **`tenants/{tenant}/`** domain/capability/asset files
7. Summarize your understanding
8. State which files you plan to change
9. Make **minimal** changes consistent with specs
10. If the change is **architectural**: update **`knowledge/`** (ADR, prompt log, change record, context packs as needed) and run **`make knowledge-index`**

Then run **`make validate`**.
