# Cursor session bootstrap (compact)

Paste at session start when editing this repo:

1. Read `AGENTS.md`
2. Read `CONSTITUTION.md` and `DOMAIN_MODEL.md`
3. Read `knowledge/INDEX.md` (or `make knowledge-index` then read it)
4. Read `knowledge/context-packs/repo-context.md`
5. Read relevant `tenants/{tenant}/...` specs for the change
6. Summarize intended change; make the **smallest coherent** diff
7. If architectural: update `knowledge/` (ADR / prompt log / change record / context pack)
8. Run `make validate`
