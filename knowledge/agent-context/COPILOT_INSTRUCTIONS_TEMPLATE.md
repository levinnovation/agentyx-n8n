# GitHub Copilot instructions template

## Purpose

Guide Copilot suggestions in GitHub / IDE integrations that read `.github/copilot-instructions.md`.

## Expected location

`.github/copilot-instructions.md`

## Required sections

1. Domain-centric model reminder
2. Forbidden top-level folders
3. Where customer code lives
4. Versioning expectations (prompts, workflows, specs)
5. No secrets; no invented API behavior
6. Pointers: `AGENTS.md`, `knowledge/context-packs/repo-context.md`

## When to update

Copilot repeatedly suggests disallowed layouts or wrong paths.

## Anti-pattern

Turning this into a full tutorial—keep it **short** and link out.
