# How to log a prompt run

1. Pick tool folder: `knowledge/prompts/<tool>/`
2. Copy `knowledge/prompts/PROMPT_LOG_TEMPLATE.md` to the next numbered file (or dated slug).
3. Record **goal**, **outcome**, **links** to PR/ADRs.
4. If verbatim prompt is unavailable, **say so**—do not invent.
5. Run `make knowledge-index` if you want discoverability in `INDEX.md` (recommended).
