# Change Record: n8n SDK and Deterministic SDLC

**Date:** 2026-05-19  
**Scope:** Repository-wide n8n workflow governance overhaul  
**Decision:** ADR-0035

## What Changed

Introduced a deterministic, YAML-driven SDLC for all n8n workflow assets:

1. **New services**:
   - `services/n8n-yaml-compiler/` — Runtime compiler (Express + TypeORM)
   - `services/n8n-node-sdk/` — Custom n8n community nodes
   - `cli/agentyx/` — CLI client for developers and CI/CD

2. **New knowledge artifacts**:
   - ADR-0035
   - Compiler runbook
   - SDK setup guide
   - Migration playbook
   - n8n SDK context pack

3. **New standards**:
   - `credential-spec.schema.json`
   - `compiler-deployment.schema.json`
   - `n8n-node-policy.md`

4. **New OpenCode skills**:
   - `n8n-authoring` — Scaffold/compile workflows
   - `n8n-deploy` — Deploy/migrate/audit

5. **Audit infrastructure**:
   - `agentyx_audit.n8n_change_log` table for full provenance tracking

6. **Makefile targets**:
   - `n8n-compile`, `n8n-deploy`, `n8n-diff`, `n8n-migrate`, `n8n-audit`, `validate-credentials`

## Why

The previous SDLC relied on manual n8n UI exports and REST API imports. This caused:
- Drift between repo and live instances
- No audit trail of who changed what
- Credentials created ad-hoc in UI
- No agent-assisted authoring

The new SDLC makes Git the sole source of truth, enables vibe-coding via OpenCode skills, and captures every node-level change with full Git provenance.

## Migration Path

- Phase 1 (this PR): Foundation — skeletons, schemas, docs
- Phase 2: Compiler core — YAML→JSON, deployers, audit logger
- Phase 3: CLI & skills — agentyx CLI, skills, Makefile
- Phase 4: Migration — live-to-repo for both tenants
- Phase 5: Cutover — Railway deployment, CI/CD
- Phase 6: Custom nodes — n8n-node-sdk, custom image

## Impact

- All future n8n changes must go through Git + `agentyx` CLI
- Live UI edits will be overwritten on next deploy
- Developers must install `@levinnovation/agentyx-cli`
- Platform ops must provision `COMPILER_TOKEN` per environment
