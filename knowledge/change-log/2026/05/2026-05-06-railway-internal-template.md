## Summary

Saved the `client-demo-agentyx` Railway project as an **internal (private) template** for LEV Innovation. All environment variables are pre-populated with safe defaults and auto-generated secrets. A post-deploy script customizes the project for each new tenant (domains, shared secrets, cross-service references).

## Motivation

- Manual tenant bootstrap required copy-pasting 50+ environment variables across 10+ services
- Inconsistent secret generation led to misconfigurations
- Each new tenant (euromobilia, levinnovation, core, etc.) took ~2 hours to provision
- Railway templates with preset variables reduce this to ~15 minutes
