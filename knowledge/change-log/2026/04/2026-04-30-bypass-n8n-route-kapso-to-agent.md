# 2026-04-30: Bypass broken n8n intake workflow — route Kapso directly to agent

**Author:** opencode-go/kimi-k2.6
**Related:** euromobilia/kitchen-quotation/quotation-assistant

## Summary

After hours of debugging, we discovered that n8n CE has deeply cached an old/broken version of the `Kapso Intake Quotation` workflow that cannot be updated through the normal DB or filesystem caches. Every execution failed at the "Forward to Agent" HTTP Request node with "The value in the JSON Body field is not valid JSON" because n8n autogenerated an invalid body expression with `?.` optional-chaining operators.

**Fix:** Route the Kapso WhatsApp webhook directly to the agent, bypassing n8n entirely. The agent now accepts the raw Kapso nested payload format and normalizes it internally.

## Changes

- `app/models.py` — Added `KapsoRawPayload` model; made `intake_data: dict | str | None` to handle n8n keypair serialization.
- `app/main.py` — Updated `/webhooks/kapso/inbound` to detect and parse both flat (n8n-normalized) and raw Kapso nested payload formats; added string-to-dict parsing for `intake_data`.
- `tenants/euromobilia/assets/deploy/n8n-hostinger/Caddyfile` — Added `/webhook/kapso-inbound` → agent rewrite rule so Kapso messages go directly to the agent without passing through n8n.
- `tenants/euromobilia/assets/workflows/n8n/kapso-intake-quotation.json` — Added `alwaysOutputData: true` on `Find Active Session`, `media_url`/`message_id` extraction in Normalize Payload, and passthrough in Forward to Agent (for when n8n is fixed later).

## n8n cleanup needed (future)

- The `Kapso Intake Quotation` n8n workflow is still active but will no longer receive webhooks because Caddy routes them to the agent.
- To restore the intake workflow later: fix the "Forward to Agent" node body in n8n UI, update the Caddyfile to remove the `/webhook/kapso-inbound` bypass, and ensure n8n's internal cache picks up the change.

## Validation

- `make validate` — passed
- Direct agent webhook test from VPS: `curl -X POST http://localhost/webhook/kapso-inbound ...` → `{"status":"ok","reply_sent":true}`

## Risks / rollback

- Intake interactive forms (buttons/lists) are temporarily unavailable because n8n is bypassed.
- Rollback: revert Caddyfile to original, restart Caddy, and fix n8n workflow via UI.
