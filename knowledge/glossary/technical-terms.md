# Technical terms

| Term | Meaning |
|------|---------|
| `asset.yaml` | Metadata manifest for an asset; required per asset folder |
| `capability.yaml` | Capability spec for a business function |
| `domain.yaml` | Domain spec |
| `tenant.yaml` | Tenant spec |
| Scaffold | Template under `templates/` used to create new instances |
| Contract | Schema-bound interface between assets (tool, channel, deployment, etc.) |
