# Customer Service Domain

Inbound engagement and lead qualification for LEV Innovation.

## Capabilities

- `lead-qualification-and-scheduling` — AI-powered customer service agent that prequalifies leads, answers questions via knowledge base, schedules meetings via Google Calendar, and syncs data to Twenty CRM.

## Channels

- **Kapso WhatsApp** — `chan-kapso-wa-customer-service`
- **Telegram** — `chan-telegram-customer-service`
- **Meta Comments** (Facebook/Instagram) — `chan-meta-comments-customer-service`

## Core Workflow

- `customer-service-core` — Reusable AI agent subworkflow with Gemini LLM, Redis memory, document loader, and Composio tool integration.
