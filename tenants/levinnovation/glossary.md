# LEV Innovation Glossary

| Term | Definition |
|------|------------|
| ICP | Ideal Customer Profile used to prioritize outbound effort |
| Lead fit score | Numeric score (0-100) generated by AI to decide qualification |
| RapidAPI LinkedIn source | Third-party API endpoint used to fetch LinkedIn company/person search data |
| Prospectador AI | Deterministic n8n workflow that sources, qualifies, and routes leads |
| HubSpot task | Manual follow-up action assigned to execute LinkedIn DM when auto-send is unavailable |
| Simple Vector Store | In-memory vector context store used in n8n for lightweight RAG |
