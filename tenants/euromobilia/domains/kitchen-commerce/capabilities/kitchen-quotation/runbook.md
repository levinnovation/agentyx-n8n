# Runbook

> Incident response for kitchen-quotation.

## Scenario: Agent Not Responding

1. Check Modal deployment status
2. Check Langfuse for error traces
3. Restart deployment if needed
4. Notify team via Slack

## Scenario: Wrong Quotations

1. Check catalog data freshness
2. Check RAG retrieval quality
3. Review recent prompt changes
4. Escalate to AI team
